# hameddrzi.github.io

Personal portfolio of Hamed Darzi: Software Engineer, Frontend & Mobile.

Built with Astro, Three.js (a single GPU particle field that morphs per section), GSAP and Lenis.
English at `/`, Italian at `/it/`.

## Develop

```bash
npm install
npm run dev      # http://localhost:4321
npm run build    # static output in dist/
```

All content lives in `src/data/cv.ts`. Pushing to `main` deploys to GitHub Pages via `.github/workflows/deploy.yml`.
